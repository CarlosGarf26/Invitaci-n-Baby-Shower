# 🍼 Invitación Digital Baby Shower "Escapada"

Una invitación web interactiva, moderna y completamente responsiva, diseñada especialmente para celebrar la llegada de nuestro Bebé Sajayin. 

## ✨ Características Principales

*   **✉️ Experiencia de Introducción:** Modal inicial en forma de sobre con sello de cera interactivo que se rompe con una animación de partículas.
*   **🎵 Música de Fondo:** Reproductor de música integrado y flotante, respetando las políticas de autoplay de los navegadores.
*   **⏳ Cuenta Regresiva:** Temporizador en tiempo real calculando los días, horas, minutos y segundos restantes para el evento.
*   **📊 Encuesta de Género (Team Niño vs Team Niña):** Mini-juego interactivo con persistencia local (`localStorage`) y lluvia de confeti según la elección.
*   **📍 Detalles del Evento:** Tarjetas informativas con itinerario (Timeline), ubicación (con enlace directo a Google Maps) y detalles de hospedaje.
*   **✉️ RSVP Inteligente:** Formulario de confirmación de asistencia que genera dinámicamente un mensaje pre-llenado y abre directamente WhatsApp para enviar la confirmación a los anfitriones.
*   **🎨 Diseño UI/UX:** Interfaz elegante "Mobile-First" con paleta de colores en tonos crema, beige y acentos pastel.

## 🛠️ Tecnologías Utilizadas

*   [React 18](https://react.dev/) - Librería principal para la interfaz de usuario.
*   [Vite](https://vitejs.dev/) - Entorno de desarrollo y bundler ultra rápido.
*   [Tailwind CSS](https://tailwindcss.com/) - Framework de utilidades CSS para el diseño rápido y responsivo.
*   [Framer Motion](https://www.framer.com/motion/) - Librería para las animaciones fluidas (apertura del sobre, modales, alertas).
*   [Lucide React](https://lucide.dev/) - Sistema de íconos SVG limpios y consistentes.
*   [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) - Para los efectos de explosión de partículas en botones y encuestas.
